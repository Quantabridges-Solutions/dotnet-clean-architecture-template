# Security

## Reporting a vulnerability

If you believe you have found a security vulnerability in this project, please report it responsibly:

- **Do not** open a public GitHub issue for security issues.
- Email the maintainers at your company’s security contact (e.g. **security@qbs-tech.com** or your designated address) with:
  - A description of the vulnerability
  - Steps to reproduce
  - Impact and suggested fix (if any)

We will acknowledge your report and work with you to understand and address the issue.

## Scope

This template is intended as a starting point for building APIs. When you fork or use it, you are responsible for:

- Keeping dependencies up to date
- Configuring authentication, authorization, and secrets appropriately
- Securing your deployment and infrastructure

We do not accept liability for misuse or misconfiguration of forked or derived projects.
